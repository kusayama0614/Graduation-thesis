# 教師管理システム - 画面遷移設計

このディレクトリには、教師管理システムのUI画面が格納されています。

## ファイル一覧

### 1. `login.html` - ログイン画面
教師がシステムにアクセスするためのログイン画面です。

**機能:**
- 教師IDとパスワードの入力フォーム
- フォームバリデーション
- エラーメッセージの表示
- レスポンシブデザイン

**デモ用ログイン情報:**
- 教師ID: `teacher001`
- パスワード: `password123`

**使用方法:**
ブラウザで `login.html` を開くだけで使用できます。

```bash
# ローカルでの確認方法
open login.html
# または
firefox login.html
```

### 2. `screen-diagram.html` - 画面遷移図
システム全体の画面遷移フローを視覚化したドキュメントです。

**含まれる内容:**
1. **ログイン・認証フロー** - ユーザーの認証プロセス
2. **メイン画面遷移図** - 全主要ページの関係図
3. **生徒管理フロー（詳細）** - 生徒管理機能の詳細なフロー
4. **ユーザーステート管理** - システムの状態遷移

**特徴:**
- Mermaid.jsを使用した自動生成ダイアグラム
- レスポンシブデザイン
- 見やすい色分けと説明文

### 3. `home.html` - ホーム画面（ダッシュボード）
ログイン後に表示される教師用のホーム画面です。

**機能:**
- 教師情報の表示
- 学習データ、解答用紙、解答データへのナビゲーション
- ステータスバーで統計情報を表示
- システムの概要と特色を説明

**デモ用アクセス:**
- デモアカウントでログイン後に表示されます

### 4. `upload-learning-data.html` - 学習データアップロード画面
過去の学習データをシステムにアップロードするための画面です。

**機能:**
- ドラッグ&ドロップでのファイルアップロード
- CSV、Excel、JSON形式に対応
- ファイル情報の編集
- データタイトルとカテゴリーの選択

**サポート形式:**
- CSV (.csv)
- Excel (.xlsx, .xls)
- JSON (.json)

### 5. `upload-answer-sheet.html` - 解答用紙アップロード画面
生徒の解答用紙をスキャン画像またはPDFでアップロードするための画面です。

**機能:**
- ドラッグ&ドロップでのファイルアップロード
- PDF、JPEG、PNG形式に対応
- テスト情報の入力
- 自動採点、OCR処理、レポート生成のオプション

**サポート形式:**
- PDF (.pdf)
- JPEG (.jpg, .jpeg)
- PNG (.png)

**処理オプション:**
- 自動採点
- OCR処理（テキスト抽出）
- 分析レポート自動生成

### 6. `view-answer-data.html` - 解答データ確認画面
システムで処理・分析された解答データを確認するための画面です。

**機能:**
- 解答データの一覧表示
- テスト名、教科、ステータスでのフィルター
- データの詳細表示
- スコアと正答数の表示
- データのエクスポート

**表示情報:**
- テスト名
- 教科
- 生徒名
- スコア（正答率）
- ステータス（待機中、処理中、完了、失敗）
- アップロード日時
- 処理時間

## 開発ガイドライン

1. **新しい画面を追加する場合:**
   - `screens/` ディレクトリに `.html` ファイルを作成
   - 統一されたスタイルを使用してください
   - 画面遷移図も更新してください

2. **スタイルの統一:**
   - カラースキーム: 紫系グラデーション（#667eea -> #764ba2）
   - フォント: Segoe UI
   - ボーダーの半径: 5-10px

3. **セキュリティの考慮:**
   - 本番環境ではハードコードされたログイン情報を使用しないでください
   - サーバー側での認証実装が必須です
   - HTTPS通信を必須にしてください
